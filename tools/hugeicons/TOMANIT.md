# Hugeicons CLI (local)

Cloned from https://github.com/codeAbinash/hugeicons

## Setup (once)

```bash
cd tools/hugeicons
npm install
npm run build
npm link
```

## Frontend config

`frontend/hugeicons.config.json` — React, output to `src/components/icons/hugeicons`.

## Usage

From `frontend/`:

```bash
ic binary-code
ic icon-name
```
